# CUP2EAT Frontend

React + Vite storefront prototype with custom editorial sections, Lenis smooth scrolling, GSAP ScrollTrigger motion, responsive layouts, product flavour discovery, wholesale pack table, enquiry form and an admin UI shell.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` (or configure API URL)
3. `npm run dev`

## Routes
- `/` public storefront
- `/admin` admin login/dashboard UI

## Important
Storefront images are sourced from remote Unsplash URLs and are placeholders for CUP2EAT's own product photography. The admin panel includes dashboard and record lists; full product editing screens, order detail controls, complete chart/report export, checkout/payment integration and comprehensive QA are not yet included.
